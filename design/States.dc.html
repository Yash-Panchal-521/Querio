Every state a document can be in

Seven, because the pipeline has seven. Four of them are one idea — "working" — and the interface says which part, so a document that stalls says where.

Queued Stored, waiting for a worker. Usually under a second.
Reading Pulling text out of the file. Extracting
Splitting Dividing it into passages. Chunking
Embedding The only one that shows a count, because it is the only one that takes long enough to want one.
Paused Amber, not red. The daily allowance ran out — nothing is wrong and nobody needs to act.
Ready Searchable. The only state where the passage count is the headline.
Failed Always carries its reason in the row, and the reason names the fix.

The interface names states for what they mean to a reader — Reading, Splitting — rather than for what the code calls them. Paused is deliberately not a failure colour: treating it as one invites a re-upload that spends the same allowance again when it returns.
